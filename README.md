# Bindu Sagar Singanamalla — Portfolio

A cinematic personal branding website designed for a **Software Engineer** specializing in Cloud Applications, CI/CD, Observability, and AI Integrations.

![Portfolio Preview](src/assets/hero.png)

## 🏗 Architectural Blueprint

This portfolio is built with a focus on structural precision and minimalist aesthetics, mirroring the "Invisible Architecture" philosophy.

### Key Features
- **Cinematic "Blueprint" Aesthetic**: High-contrast layout with a custom color palette (`#F5F0E8` cream, `#0D0D0D` ink, `#C04B2A` rust).
- **Single-Page Application (SPA)**: A seamless long-scroll experience with integrated breadcrumb navigation.
- **Motion-Rich Interface**: Fluid transitions and micro-interactions powered by **Framer Motion**.
- **Self-Contained Architecture**: Consolidated logic within a lean `App.jsx` for optimal performance and maintainability.
- **Responsive Design**: Optimized for everything from ultra-wide displays to mobile devices.

## 🛠 Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: Vanilla CSS (Modern CSS Variables & Grid)
- **Typography**: Syne, Cormorant Garamond, DM Mono
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Bindu-Sagar/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 📐 Project Structure
```text
portfolio/
├── src/
│   ├── App.jsx        # Main application (Single-File Architecture)
│   ├── index.css      # Core Design System & Tokens
│   └── main.jsx       # React Entry point
├── public/            # Static assets
├── vercel.json        # Deployment configuration
└── vite.config.js     # Build configuration
```

## 🌐 Deployment

This project is pre-configured for **Vercel**. To deploy:
1. Connect your GitHub repository to Vercel.
2. Use the default build settings (`npm run build`, `dist` directory).
3. The `vercel.json` ensures clean SPA routing for the single-page layout.
